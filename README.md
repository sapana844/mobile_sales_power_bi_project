# mobile_sales_power_bi_project
My Power BI Project

1.Project Headline

Mobile Sales Dashboard | Interactive Sales Performance Analysis in Power BI

2.Short Description

An interactive Power BI dashboard designed to analyze mobile phone sales performance across cities, brands, models, payment methods, and time periods, enabling stakeholders to monitor KPIs, identify trends, and make data-driven business decisions.

3.Tech Stack

Power BI Desktop
Power Query (Data Transformation)
DAX (Measures & KPIs)
Microsoft Bing Maps (Geo Visualization)
Excel / CSV Dataset (Source Data)
Data Modeling & Relationships

4.Data Source

Mobile sales transaction dataset containing:
Sales Amount
Quantity Sold
Transaction Details
Mobile Brand
Mobile Model
City/Location
Payment Method
Customer Ratings
Transaction Date

5.Project Highlights

📊 Monitored key business KPIs including ₹769M Total Sales, 19K Units Sold, and 4K Transactions.

🌍 Visualized geographical sales distribution across major Indian cities using an interactive map.

📈 Analyzed monthly sales quantity trends to identify peak and low-performing periods.

📱 Compared sales performance across mobile brands and individual phone models.

💳 Evaluated customer payment preferences through payment method transaction analysis.

⭐ Tracked customer satisfaction using rating status metrics (Good, Average, Poor).

📅 Enabled dynamic filtering by month, brand, mobile model, and payment method.

📉 Identified sales patterns by weekday to support operational and marketing decisions.

🔍 Built a fully interactive dashboard with drill-down capabilities and slicers for deeper insights.

🚀 Improved business visibility by consolidating multiple performance metrics into a single reporting interface.



Developed an interactive Power BI Mobile Sales Dashboard analyzing ₹769M sales across 4K transactions, leveraging DAX, Power Query, and geospatial visualizations to uncover sales trends, customer behavior, and brand performance.
